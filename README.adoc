= PARG grammars

The diagram grammars in https://github.com/parsanol/parsanol-rs[PARG] —
the parsanol grammar language (ABNF-flavoured, PEG semantics), one
directory per family.

This repository is the canonical home of the grammars and their
compiled artifacts; the https://github.com/etassia/etassia[etassia] gem
consumes them for its native parse path (etassia/etassia#342).

== Layout

* `mermaid/mermaid.parg` — the Mermaid grammar source (the contract).
  Each diagram type is one entry; the rules mirror etassia's Parslet
  grammars (`lib/etassia/parser/grammars/*.rb`) rule for rule.
* `mermaid/mermaid.json` — the compiled Mermaid artifact (checksummed
  envelope).
* `plantuml/plantuml.parg` — the PlantUML grammar source, mirroring
  etassia's `lib/etassia/notation/plantuml/` readers (same whitespace
  set as the Mermaid grammar, with PlantUML's single-quote line
  comment).
* `plantuml/plantuml.json` — the compiled PlantUML artifact.

Each artifact is compiled with the released parsanol:

----
parsanol parg compile mermaid/mermaid.parg -o mermaid/mermaid.json
parsanol parg compile plantuml/plantuml.parg -o plantuml/plantuml.json
----

== CI

CI installs the released `parsanol` gem and runs, per family, on every
push/PR:

* `parsanol parg test <family>.parg` — the embedded accept/reject tests
* a fresh compile checked for *payload parity* against the committed
  artifact (envelope `checksum`, `compiler_version` and `unicode_tables` stripped; the last is the Ruby build stamp, e.g. "onigmo (Ruby 3.4.8)")

== How etassia uses it

etassia vendors each artifact and routes a diagram type to its entry
when the parsanol engine loads. The native path is an accelerator only:
input an entry rejects, an unreadable encoding, or a builder decline
(for example Parslet's `"[]"` for an empty accessibility text) all fall
back to the hand-written grammars, which stay the source of every
positioned `ParseError`. Model parity is enforced in etassia's specs
over the whole corpus plus an edge table. Set
`ETASSIA_NATIVE_PARSER=ruby` to force the fallback.

|===

== Runtime bindings

The grammars are engine-neutral JSON. Ruby consumes them through
`Parsanol::PARG::Artifact` (native Rust extension, pure-Ruby atom
runtime as engine fallback). Other runtimes: see etassia/etassia#343.
